# Galaxy luminosity function data

Powers the interactive at [/explore/galaxy-lf/](https://skoonkor.github.io/explore/galaxy-lf/).

Measured in Koonkor et al. (2026), *The PAU Survey: the i-band galaxy luminosity function from the
present-day to z = 2*, MNRAS **547**(3), 1–24, [doi:10.1093/mnras/stag362](https://doi.org/10.1093/mnras/stag362).

`lf.json` is generated by [`tools/build_lf_data.py`](https://github.com/SKoonkor/skoonkor.github.io/blob/main/tools/build_lf_data.py)
from the paper's own tables. It is a repackaging for the browser, not a new measurement.

## What is in it

5 bands (`u g r i z`) × 8 redshift slices × 24 absolute-magnitude bins.

| key | meaning |
|---|---|
| `bins` | bin centres, `M − 5 log₁₀ h`. Identical for every band and slice, so it is stored once |
| `true` | GALFORM lightcone, error-free |
| `gaussLo` / `gaussHi` | lightcone with Gaussian photo-z errors (σ68 × 2), 16th/84th percentile |
| `bcnzLo` / `bcnzHi` | lightcone with the empirical BCNz photo-z, which has outliers, 16th/84th percentile |
| `w1`, `w3` | the measured PAUS luminosity function in fields W1 and W3 |
| `w1Lo`/`w1Hi`, `w3Lo`/`w3Hi` | ± total 1σ (Monte-Carlo + jackknife), as log-space bounds |
| `completeness` | faint limit per band and slice, set by the PAUS `i_AB ≤ 23` selection |

**All φ values are `log₁₀(φ / [h³ Mpc⁻³ mag⁻¹])`**, which is the axis the paper plots.

**`null` means an empty bin** — no galaxies, not a measured zero. About 38% of the values. The source
tables write these as `phi = 0`; they are converted so that nothing tries to plot `log₁₀(0)`.

## Two things to know before using it

- **Brighter galaxies have more negative M.** The demo plots the axis reversed, brighter to the
  right, as the paper does.
- **The completeness limit is a selection effect, not a measurement.** The luminosity function is
  complete *brighter* than the limit and incomplete fainter than it. Fainter than the line the survey
  simply stops seeing galaxies, so the points there are lower limits.

`phi_combined` / `err_combined` (the inverse-variance W1+W3 combination) exists in the source tables
and is the headline number of the paper, but is not shipped here: the demo plots the two fields
separately so their scatter is visible.

For the authoritative tables, use the paper.
