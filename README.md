# skoonkor.github.io

Personal site of Suttikoon Koonkor — postdoctoral researcher in astrophysics at NARIT.
Live at <https://skoonkor.github.io/>.

Built with [Astro](https://astro.build) on the
[Astro Cactus](https://github.com/chrismwilliams/astro-theme-cactus) theme by Chris Williams (MIT).

## Running it

Needs Node 22.12+ (see `.nvmrc`) and pnpm 10.

```bash
pnpm install
pnpm dev        # local dev server
pnpm build      # static build into dist/
pnpm postbuild  # Pagefind search index -- must be run after build
pnpm check      # astro check + biome
```

Deployment is automatic: pushing to `main` runs `.github/workflows/deploy.yml`, which builds and
publishes to GitHub Pages.

## The two custom pieces

**The cosmic web** in the left and right margins is IllustrisTNG TNG300 gas density, running
z = 10 at the top of a page to z = 0.07 at the bottom. Regenerate the frames with:

```bash
tools/build_cosmic_frames.sh path/to/tng300_most_massive_cluster_gas_1080p.mp4
```

It is decoration: hidden below 1100px, under `prefers-reduced-motion`, on metered connections and
in print, with a static frame as the base layer so the margins are never empty.

**The PCA/SED demo** at `/explore/pca-sed/` reconstructs stellar population spectra from a
principal component basis, in the browser. The basis reproduces the result in the MSc thesis it
comes from: 87 components for better than 1% error, against 85 published. Regenerate and verify:

```bash
python3 tools/build_pca_sed.py    # needs FSPS with SPS_HOME set
python3 tools/verify_export.py    # reconstructs from the written files only
node tools/test_colour.mjs        # checks the CIE colour pipeline
```
